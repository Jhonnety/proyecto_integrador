https://www.datos.gov.co/Educaci-n/Resultados-nicos-Saber-11/kgxf-xxbe

--------------------------------------------------------------------------------
RESULTADOS DEL MODELO
--------------------------------------------------------------------------------

Modelo final : HistGradientBoostingClassifier (con class_weight balanceado)
               dentro de un Pipeline con todo el preprocesamiento

Desempeno sobre el conjunto de prueba (30 % no visto):

    Accuracy        0,7360
    Precision       0,4064
    Recall          0,7018
    F1              0,5147   <- metrica principal
    ROC-AUC         0,8020
    PR-AUC          0,5209
    Bal. Accuracy   0,7231
    MCC             0,3753

Metas fijadas en la fase 1: F1 >= 0,50 y ROC-AUC >= 0,75. Ambas se cumplen.
